# 财务模块

管理账户、发票、支付、退款、充值等财务数据，掌控本租户资金往来。

## 功能说明

- 统一管理财务凭证
- 跟踪支付与退款
- 处理发票申请
- 管理用户充值订单

## 子模块

| 模块 | 说明 |
|------|------|
| 支付订单 | 查看和管理所有支付订单 |
| 退款 | 审批和处理退款申请 |
| 充值订单 | 查看用户充值记录，支持余额/积分充值 |
| 用户账户 | 查看用户账户余额、积分及变动日志 |
| 发票 | 管理发票申请和已开具发票 |
| 结算计划 | 配置结算计划和凭据 |

## 操作指引

1. 通过左侧导航进入「财务模块」集群
1. 选择对应子模块进行管理
