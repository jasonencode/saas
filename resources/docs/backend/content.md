# 内容管理

管理文章、分类、标签、评论、通知等内容，为平台前台提供资讯与帮助支持。

## 功能说明

- 统一管理内容与分类
- 管理内容标签
- 审核用户评论
- 维护单页与版本

## 子模块

- [内容管理](content/contents)
- [分类管理](content/categories)
- [标签管理](content/tags)
- [评论管理](content/comments)
- [单页管理](content/single-pages)

## 操作指引

1. 通过左侧导航进入「内容管理」集群
2. 选择对应子模块进行管理
