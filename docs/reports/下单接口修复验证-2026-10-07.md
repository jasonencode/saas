## 四、⚠️ 必须处理：异常映射副作用（安全风险）

### 4.1 问题

新增的 `RuntimeException` 分支会**连带捕获数据库异常**：

```
PDOException        extends RuntimeException          （PHP 内核）
QueryException      extends PDOException              （Laravel）
```

因此 `QueryException` 落入业务异常分支，返回 **400 + 原始异常消息**（含完整 SQL 与绑定值）。

### 4.2 运行时实证

```php
$ex = new QueryException('pgsql', 'select * from "users" where "password" = ?',
        ['$2y$04$secretpasswordhash'], new PDOException('...relation "users" does not exist'));
ApiExceptionHandler::handle($ex, $request);
```

| 状态 | HTTP | 响应体 |
|---|---|---|
| 基线 | 500 | `{"code":500,"message":"服务器内部错误，请稍后重试"}` |
| **当前** | **400** | `{"code":400,"message":"SQLSTATE[42P01]: Undefined table: relation \"users\" does not exist (Connection: pgsql, SQL: select * from \"users\" where \"password\" = $2y$04$secretpasswordhash)"}` |

**双重问题**：
1. **信息泄露**：生产环境原本被 `handleGenericException` 掩码，现直接对外输出 SQL 语句与绑定值（可能含密码哈希、令牌、用户隐私）。当前本地 `APP_ENV=production`，线上同样受影响。
2. **语义错误**：数据库故障被上报为 400（客户端错误），监控告警会把真实服务端故障统计成客户端问题。

### 4.3 同类风险

- `Illuminate\Http\Exceptions\HttpResponseException` 同属 `RuntimeException` 子类，会被降级为 400 并丢失原始响应体。项目内暂未使用（已全量检索确认），但属隐患。
- `ModelNotFoundException` / `NotFoundHttpException` 同属 `RuntimeException`，因分支顺序在前已正确分流，**无问题**。

### 4.4 最小修复补丁

在业务异常分支之前插入排除分支，并补充 `use PDOException;`：

```php
            $exception instanceof HttpException => self::handleHttpException($exception),
            // PDO/QueryException 属 RuntimeException 子类但为服务端故障，
            // 必须排除在业务异常之外，避免返回 400 并泄露 SQL 与绑定值
            $exception instanceof PDOException,
            $exception instanceof HttpResponseException => self::handleGenericException($exception),
            // 业务异常：可预期的用户操作错误（券不可用、库存不足、履约方式不支持、
            // 地址不正确等），返回 400 并透出原始提示
            $exception instanceof InvalidArgumentException,
            $exception instanceof RuntimeException => self::handleBusinessException($exception),
```

补丁分支顺序已用独立脚本验证，各异常归类结果：

| 异常 | 补丁后归类 |
|---|---|
| `QueryException` / `PDOException` | 通用异常 500 ✅ |
| `HttpResponseException` | 通用异常 500 ✅ |
| `RuntimeException` / `InvalidArgumentException` | 业务异常 400 ✅ |
| `HttpException` 家族 / `ModelNotFoundException` | 原状态码 ✅ |
